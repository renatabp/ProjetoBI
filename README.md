# Atividade de Inteligência Analítica em Negócios 

Esta atividade teve como objetivo consolidar os conhecimentos adquiridos na disciplina por meio da criação de um dashboard interativo no Power BI. 

Trabalhei com base em um dataset de uma empresa chamada IAN-Store, realizei análises descritivas e diagnósticas, apliquei técnicas de visualização e storytelling, e implementei um modelo preditivo simples.


Por fim, elaborei um relatório para destacar os principais insights e as aplicações práticas para o contexto de negócios.
